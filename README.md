# 💪 AIで月収100万円稼ぐマッチョ

AIの基礎を **マッチョキャラ × 15秒ショート動画** で発信していく、個人の学習＆発信プロジェクト。

> **一番の目的は「自分自身がAIを根本から学ぶこと」。**
> 発信（復習・アウトプット）は、その学びを定着させるための手段。
> 「人に説明できる ＝ 本当に理解している」を地で行く。

---

## 🎯 コンセプト

| 項目 | 内容 |
|------|------|
| 主人公 | AIで月収100万円を稼ぐ**マッチョ** |
| テーマ | AIの基礎を、誰でもわかる言葉で1テーマずつ筋トレのように積み上げる |
| 投稿先 | **Instagram Reels**（縦型 9:16 / 1本15秒前後） |
| トーン | ハイテンション・ポジティブ・筋肉メタファー（「AIも正しく鍛えれば裏切らない」） |
| 編集方針 | **最低限**。基本は1カットのトーク＋簡単なテロップのみ |

### マッチョの口調（キャラ設定）

- 一人称は「俺」、語尾は「〜だぜ」「〜しようぜ」
- 筋肉と絡めて励ます（例:「基礎を知れば、AIは裏切らない」）
- 専門用語は**必ず一言で噛み砕く**（難しいまま投げない）
- 1本につき**伝えるのは1テーマだけ**。盛らない。

## 🎬 撮影〜投稿のシンプルな流れ

編集を凝らない前提で、毎回これだけ回せばOK。

1. **台本を1本選ぶ**（`台本/` の中から）
2. **撮る** … スマホ縦向き・顔出しトーク1カット（背景はジム風 or 部屋でOK）
3. **テロップを乗せる** … 台本の「テロップ案」をそのまま画面に表示
4. **音だけ整える**（任意） … BGM1曲 + 必要なら無音カット
5. **投稿** … キャプション＋ハッシュタグ（台本に記載）

> 💡 凝った編集はしない。**続けることが最強の筋トレ**。

## 🧱 1本＝15秒の型（全台本共通）

| 時間 | パート | 役割 |
|------|--------|------|
| 0〜3秒 | **フック** | 「AIで月収100万？その前に〇〇って知ってるか？」で掴む |
| 3〜12秒 | **本編** | 今日の1テーマを一言で説明 |
| 12〜15秒 | **オチ / CTA** | 筋肉で締める＋「次回もっと鍛えるぞ」 |

> 日本語ナレーションの目安: 15秒 ≒ **70〜100文字**。詰め込みすぎ注意。
