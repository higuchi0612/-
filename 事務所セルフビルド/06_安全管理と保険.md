# 06. 安全管理と保険

セルフビルドの失敗で取り返しがつかないのは、予算でも工期でもなく**事故**。
建設業の死亡事故の第1位は**墜落・転落**。素人現場ならリスクはプロ以上と心得る。

---

## 1. 法律上の立ち位置

- 社員に作業させる時点で、会社には**労働安全衛生法上の事業者責任**が発生する(建設業許可の有無と無関係)
- 具体的には: 必要な特別教育の実施、保護具の支給、作業主任者が必要な作業の管理、危険箇所の措置
- 社長1人で作業する分には労安法の適用は緩いが、**安全基準そのものは全員同じものを守る**

---

## 2. 高所作業のルール(最重要)

| ルール | 内容 |
|---|---|
| 高さ2m以上 | 作業床(足場)を設ける。設けられない場合は**フルハーネス型墜落制止用器具**を使用 |
| フルハーネス使用者 | **特別教育(学科+実技・1日)**を受講させる。建災防等で随時開催・1万円前後 |
| 足場 | 高さ5m以上の組立・解体は**足場の組立て等作業主任者**が必要 → **組立解体込みで足場業者に外注**(`04`) |
| 脚立 | 天板に乗らない・またがない。1.5m以上の作業は原則足場・立ち馬で |
| 屋根作業 | 端部に近づく作業は必ずハーネス+親綱。荒天・強風日は中止(風速10m/s目安) |

## 3. 現場の基本装備

### 個人装備(1人あたり2〜4万円)

- [ ] ヘルメット(墜落時保護用・あご紐必須)
- [ ] フルハーネス+ランヤード(新規格品)
- [ ] 安全靴(JSAA/JIS)
- [ ] 保護メガネ(丸のこ・グラインダ時は必須)
- [ ] 防塵マスク(石膏ボード切断・グラスウール施工時)
- [ ] 耳栓(釘打ち機・丸のこ)
- [ ] 革手袋/耐切創手袋 ※**回転工具では巻き込まれ防止のため軍手禁止**

### 現場設備

- [ ] 消火器(現場に1本)
- [ ] 救急箱+近隣の救急病院を貼り出す
- [ ] 漏電遮断器付き仮設分電盤・屋外用延長コード
- [ ] 単管・カラーコーンで第三者立入防止(特に夜間・休日)
- [ ] 熱中症対策(WBGT計・塩飴・休憩ルール)

---

## 4. 電動工具の安全(事故の第2グループ)

- **丸のこ**: キックバックが最多事故。①材の下に空間(逃げ)を作らない置き方をしない ②手前に立たない ③刃の出は材+5mm ④「丸のこ等取扱作業者教育」の受講を推奨
- **釘打ち機(エア)**: 二度打ち・空打ち禁止。ホース接続時はトリガーに指を掛けない
- **グラインダ**: 砥石交換は特別教育(`04`)。火花方向に可燃物・人を置かない
- 全工具共通: 刃・砥石の交換時は**必ず電源・エアを抜く**

---

## 5. 保険 — 3層で掛ける

| 保険 | 何をカバー | 備考 |
|---|---|---|
| **労災保険** | 作業中の社員のケガ | 雇用があれば当然に適用対象。**事務所業として加入済みでも、建設作業をさせることを労働基準監督署・労働保険事務組合に相談**しておく(業種・料率の整理)。役員は労災対象外 → **中小事業主の特別加入**を検討 |
| **建設工事保険** | 工事中の建物自体の損害(台風・火災・盗難) | 施主自身で掛けられる。工期分・数万円〜。上棟後〜完成までが特に重要 |
| **請負業者賠償責任/施設賠償責任保険** | 第三者への損害(資材落下で隣家・通行人に被害等) | セルフビルドは元請の保険が無いので自前で必須 |
| (完成後)火災保険 | 完成した建物 | 事業用物件として。**検査済証があると引受・保険料で不利にならない** |

---

## 6. 現場運営ルール(自分たちとの約束)

- [ ] 作業前に5分の**KY(危険予知)ミーティング**: 今日やる作業・危ない箇所・中止基準を声に出す
- [ ] **単独作業の禁止**(特に高所・重量物・電動工具)。やむを得ない場合は定時連絡
- [ ] 疲労時・雨天時の高所作業は中止。「今日中に終わらせたい」が事故の合図
- [ ] 整理整頓: 端材と釘の出た材は毎日片付ける(踏み抜きは定番事故)
- [ ] 15時以降は新しい工程を始めない(疲れ+焦り+薄暗さの三重苦)
- [ ] 事故・ヒヤリハットは全部記録して翌朝共有

---

## 7. 品質の自己検査(安全と同じ仕組みで回す)

各工程の完了時に、チェックシート+写真📷で自己検査してから次へ進む。

- 基礎: 配筋ピッチ・かぶり・アンカー位置
- 構造: 金物リスト照合・釘ピッチ・めり込み
- 防水: テープの貼り順・重ね寸法・破れ
- 断熱: 充填の隙間・防湿シートの連続
- 電気・配管: 図面との照合(電気は工事士の自主検査+受電時の竣工検査)

> 💡 プロの現場は「検査があるから品質が出る」。セルフビルドは検査を自分で仕組み化しない限り品質は運任せになる。
