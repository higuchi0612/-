# 08. 相見積仕様書 — 木造在来 vs 軽量鉄骨

「安い方」を**同じ土俵で**比較するための見積依頼条件。
このページをそのまま見積依頼書のベースにしてよい(依頼先: 木造=プレカット工場2社以上/軽鉄=鉄骨加工業者 or システム建築メーカー2社以上)。

---

## 1. 共通条件(両構造とも同一で依頼)

| 項目 | 条件 |
|---|---|
| 用途・階数 | 事務所・平屋 |
| 規模 | 延べ約137㎡(外形目安 16.38m×8.19m。多少の増減可、200㎡以下厳守) |
| 屋根 | 片流れ(1.5〜2.5寸)ガルバリウム鋼板 立平葺き。太陽光後載せの可能性あり(積載考慮) |
| 天井高 | 2.5m(最高高さは13m以下・軒高9m以下に余裕で収まる) |
| 執務室 | **9.1m×7.28m程度を無柱**にしたい(スパン計画の条件として明記) |
| 基礎 | ベタ基礎・**自社施工**(見積対象外。ただしアンカーボルト/柱脚アンカーの仕様・配置図は見積側の提供範囲) |
| 建設地 | 福岡県(垂直積雪・風速・地震地域係数は建設地基準で) |
| 準耐火等の要件 | 防火・準防火地域外の想定(宿題確認後に確定)。平屋事務所137㎡なら耐火要求なしの見込み |

## 3. 軽量鉄骨への見積依頼範囲

- [ ] 構造計算(許容応力度)・構造図一式 ※新3号でも計算・図書は作る前提で

## 4. 比較表(見積が揃ったら記入)

| 比較項目 | 木造在来 | 軽量鉄骨 | 備考 |
|---|---|---|---|
| ① 構造体+加工費 | 万 | 万 | |
| ② 建て方費(クレーン・人工) | 万 | 万 | 軽鉄は自社とび班施工なら圧縮可 |
| ③ 構造計算・図書作成費 | 万 | 万 | 木造は壁量計算(プレカット込みが多い) |
| ④ 基礎への影響差 | 万 | 万 | 軽鉄は柱脚アンカー精度がシビア/木造は布基礎的配置 |
| ⑤ 断熱・下地の補正 | 万 | 万 | **軽鉄は熱橋対策+ボード用木下地で増額しがち。ここを忘れると比較を誤る** |
| ⑥ 防蟻・防錆の維持費 | 万 | 万 | 木造=防蟻5年毎/軽鉄=基本不要 |
| ⑦ 納期 | 週 | 週 | |
| **構造起因トータル(①〜⑤)** | **万** | **万** | **これで判定する。①だけで決めない** |

### 判定基準

1. **構造起因トータル(①〜⑤)の安い方**を基本採用
2. 差が5%以内なら: 自社の施工しやすさ(とび班の鉄骨経験 vs 大工手配)と納期で決定
3. どちらでも執務室の無柱条件(9.1×7.28m)が満たせることを確認してから契約

### 事前の見立て(参考)

- 一般論ではこの規模・平屋・断熱要求ありなら**木造が5〜20%安い**ことが多い
- ただし樋口工業は**とび・土工班の建て方内製**と**鉄骨業者との取引**があり得るため、軽鉄が逆転する余地が普通の会社より大きい。だからこそ相見積の価値がある
