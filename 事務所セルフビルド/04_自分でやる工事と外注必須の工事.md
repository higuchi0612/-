# 04. 自分でやる工事と、外注必須の工事

セルフビルドは「全部自分でやる」ことではなく、**法律と安全とコスパで工事を仕分けること**。

---

## 1. 仕分け早見表

| 工事 | 自社施工 | 根拠・理由 |
|---|:---:|---|
| 基礎工事 | ◎(既知) | 資格不要 |
| 土台敷き・木工事全般 | ◎ | 資格不要 |
| 建て方(上棟) | △ | 資格は不要だが技術・安全上、経験者の応援+クレーン外注 |
| 屋根 | ○ | 資格不要。高所リスクと雨仕舞い品質で外注も有力 |
| 防水・外壁 | ○ | 資格不要 |
| 断熱・内装・建具 | ◎ | 資格不要 |
| **電気工事** | **✕(資格必須)** | 電気工事士法。無資格施工は**違法**(罰則あり)。火災時に保険が下りないリスクも |
| **水道引込・給水装置工事** | **✕(指定工事店のみ)** | 水道法。自治体の**指定給水装置工事事業者**でなければ施工不可 |
| **下水接続・排水設備工事** | **✕(指定工事店のみ)** | 下水道法・自治体条例。**排水設備指定工事店**制度 |
| 浄化槽(下水が無い場合) | ✕ | 浄化槽工事業登録・浄化槽設備士が必要 |
| ガス工事 | ✕ | ガス事業者・有資格者のみ(プロパンならガス屋が無償〜安価で配管することが多い) |
| 地盤改良 | ✕(事実上) | 重機・品質保証の世界 |
| 足場の組立・解体 | △ | 高さ5m以上は**作業主任者**が必要 → リースより「組立解体込み外注」が現実的 |
| エアコン設置 | △ | 真空引き・冷媒配管の品質問題。外注推奨 |
| 誘導灯・自火報(必要な場合) | ✕ | 消防設備士 |

---

## 2. 電気工事 — 2つの選択肢

### 選択肢A: 第二種電気工事士を自社で取る(推奨)

- 一般住宅・小規模事務所(低圧受電)の屋内配線は**第二種電気工事士**でフルにできる
- 試験は**年2回**(上期・下期)。学科(CBT)+技能試験
- 合格率は学科6割前後・技能7割前後。**独学3か月・教材と工具で5万円**ほどの投資
- セルフビルダーの定番資格。**建設と並行して社員1人が取れば、配線・器具付け・将来のレイアウト変更まで全部内製化できる**
- 注意: 電力会社への申込・受電(竣工検査)まわりは登録電気工事業者経由が必要なケースがあるため、最後の受電だけ電気工事店と組む形が現実的

### 選択肢B: 電気工事店に一式外注

- 30坪事務所の新築配線一式で**50〜100万円**が目安
- その場合も**電気図(コンセント・照明・LAN位置)は自社で描いて渡す**と、追加変更の手戻りと費用が激減する

## 3. 給排水 — 最初から外注前提で組む

- **道路の本管からの引込み**と**宅内の給排水配管**は、自治体の指定工事店しか施工できない(無指定の施工は接続を拒否される)
- 発注のコツ:
  - 見積は**2〜3社の相見積**(指定工事店リストは市の水道課Webにある)
  - 「器具はこちらで支給・取付調整だけお願い」等の**分離交渉**で圧縮できることがある
  - 水回りを1か所に固めた設計(`02`)が最大のコスト削減
- 費用目安(条件で大きく変動):
  - 給水引込(前面道路に本管あり): 30〜60万円
  - 下水接続: 30〜80万円
  - 宅内給排水配管一式: 30〜60万円
  - 本管が遠い/浄化槽が必要な場合は+100万円超もあり得る → **土地選定段階で確認**

## 4. 「資格は不要だが講習・教育が要る」作業(労働安全衛生法)

社員=労働者が作業する以上、労安法の教育義務は会社に掛かる。詳細は `06`。

| 作業 | 必要なもの |
|---|---|
| フルハーネス型墜落制止用器具の使用 | 特別教育(1日) |
| 高さ5m以上の足場の組立・解体 | 作業主任者(技能講習)→ 外注で回避 |
| 玉掛け(1t以上のクレーン) | 技能講習 → 建て方はオペ・玉掛けごと外注で回避 |
| 丸のこ | 法定義務ではないが「丸のこ等取扱作業者教育」受講を推奨 |
| 自由研削砥石(ディスクグラインダの砥石交換) | 特別教育 |

## 5. 外注先の探し方・付き合い方

- **プレカット業者**: 構造の相棒(`02`)。地域の木材市場・材木店経由が入口
- **建て方応援の大工**: 材木店・プレカット業者に紹介を頼むのが最短。「セルフビルドの建て方応援」は珍しい依頼ではない
- **電気・水道・板金**: 地元の個人事業の職人が小回りと価格で有利。建材店・金物店の店頭で聞くと繋がる
- 発注時は必ず**書面(メールでOK)で範囲・金額・時期**を残す
- 職人には**現場を段取りして待たせない**のが最大の礼儀(=次も来てくれる)
