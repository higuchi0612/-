# 05. 予算と工程表

> ⚠️ **このページは計画初期の25坪モデル。現行計画(137㎡/41.5坪・予算2,000〜2,500万)の
> 概算は `07_面積計画とゾーニング案.md` を参照。** 工程表の考え方・削る順番は引き続き有効。

モデルケース: **木造平屋・在来軸組・約82㎡(25坪)・片流れガルバ屋根・サイディング外壁**の事務所。

> ⚠️ 金額は2025〜2026年時点の一般的な概算(地域・仕様・市況で±3割は動く)。
> 実行予算は必ず見積を取って `見積/` に保存し、この表を実数で更新していくこと。

## 2. 資金・キャッシュフローの注意

- 支払いピークは**プレカット納品時**と**サッシ・外壁納品時**。材料は原則「納品時払い」なので、着工前に総予算の6割は現金化しておく
- 融資を使う場合: セルフビルドは住宅ローン型の融資が使いにくい。**事業性融資(日本政策金融公庫・銀行の設備資金)**として「建設計画書+この予算表」で申し込むのが現実的
- 領収書は**全部保管**(資産計上・消費税・登記の所有権証明の3役)

## 3. 工程表モデル

### パターンA: 専念型(平日も2〜3人が作業)

| 月 | 工程 |
|---|---|
| 1 | 設計・仕様決定・地盤調査 |
| 2 | 確認申請〜確認済証/プレカット発注・職人手配 |
| 3 | 基礎工事 |
| 4 | 土台敷き・**建て方**・屋根・耐力壁 |
| 5 | サッシ・防水・外壁(足場期間) |
| 6 | 電気配線・給排水・断熱 |
| 7 | 内装下地・仕上げ |
| 8 | 設備器具・外構・**完了検査**・登記 |

→ **約8か月**

### パターンB: 週末型(土日中心・2〜3人)

- 上記の3倍弱かかると見る → **18〜24か月**
- 週末型の鉄則: **建て方から屋根防水完了までだけは連休+応援で一気にやる**(構造材を雨に晒す期間を最短に)

## 4. 予算を削るならこの順番

1. **面積を削る**(1坪減=30〜50万円減。最強)
2. 水回りを1か所に集約(`02`)
3. 屋根・外壁をガルバに統一(材工とも安い・軽い)
4. 二種電工を取って電気を内製化(▲30〜60万)
5. 内装仕上げのグレード(塗装は後からいくらでも上げられる)

### 削ってはいけないもの

- 構造材・金物・釘(建物の命)
- 防水部材(ルーフィング・防水テープ・シート)
- 断熱(2025年から法義務。後から入れ直すのは新築の3倍手間)
- 足場と安全装備(`06`)
- 予備費10%
