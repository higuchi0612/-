# 🏗️ 樋口工業 新事務所 自社施工プロジェクト

樋口工業有限会社(福岡県・特定建設業)の新事務所を、自社の手で建てるためのプロジェクトドキュメント。

> **現在の計画(v10「部門分室」):** 平屋・**事務所 130.4㎡(8.19×15.925m)を441-5(赤の場所)に建設**。
> **会議室19.9㎡・工務室24.8㎡・事務室51.1㎡(役員・経理・事務)をホール受付から分けた部屋割り**。
> 複合機は工務室・事務室に各1台(工務室はプロッタも)。席は現メンバー名入り(現12名+予備3=15席)。
> **玄関=西面**・北面=道路際で出入口なし(サイン帯の顔)。黒ガルバ×八女杉の玄関。**GYM計画は完全廃止**。
> 朝礼土間・シャワー・日報コーナー・休憩室・庭園演出は施主決定で不採用(`13`は記録として保存)。
> 概算1,200〜1,700万円・完成目標2027年夏〜秋。
> **農地転用許可(441-5)が着工の前提**——固定資産税は宅地並み課税なので農業委員会に課税明細持参で相談。
> 確定情報と決定事項は **`00_前提条件と決定事項.md`** が正。以降の章と食い違ったら00を信じる。
> (`01`〜`06`は計画初期の一般論として書かれており、「素人セルフビルド」前提の記述は
> 本職の建設会社である実態に合わせて読み替える)

## 🎯 まず結論(推奨プラン)

| 項目 | 推奨 | 理由 |
|------|------|------|
| 構造 | **木造・在来軸組工法** | セルフビルドの定番。材料・情報・応援人材が最も手に入りやすい |
| 階数 | **平屋** | 足場上・高所作業が激減し、安全面・技術面のハードルが大幅に下がる |
| 延べ面積 | **100㎡以下(約30坪以下)** | ①建築士資格なしで自分で設計できる ②確認申請の構造審査が簡素な「新3号建築物」に収まる |
| 屋根 | 片流れ or 切妻 + ガルバリウム鋼板 | 形が単純なほど雨仕舞いの失敗が減る。軽い屋根は耐震にも有利 |
| 外壁 | 窯業系サイディング or ガルバ | 施工マニュアルが整備されており素人でも品質を出しやすい |

**「木造・平屋・100㎡以下」に収めることが、法規面でも技術面でも最大の攻略法。**
これを超えると建築士への設計委託が必須になり、審査・構造のハードルも一段上がる(詳細は `01_法規・資格・手続き.md`)。

## 🗺️ 全体フロー

```
[企画]  土地と規模を決める → 資金計画
   ↓
[調査]  用途地域・法規チェック → 地盤調査(SWS試験)
   ↓
[設計]  平面図・立面図・仕様決め → 省エネ基準の確認
   ↓
[申請]  建築確認申請 → 確認済証の交付
   ↓
[着工]  地縄張り・遣り方 → ★基礎工事(既知の領域)★
   ↓
[構造]  土台敷き → 建て方(上棟) → 屋根 → 耐力壁・金物
   ↓
[外装]  サッシ → 防水 → 外壁
   ↓
[中間]  電気配線(※資格) → 給排水配管(※指定工事店) → 断熱
   ↓
[内装]  石膏ボード → 床 → 仕上げ → 建具 → 設備器具
   ↓
[完成]  完了検査 → 検査済証 → 建物表題登記 → 火災保険 → 使用開始
```

## ⚠️ 最重要注意 3か条

1. **電気工事は無資格でやってはいけない**(電気工事士法違反。火災保険も無効になり得る)。
   → 第二種電気工事士を取るか、電気工事店に外注。詳細は `04`。
2. **水道の引込・接続は自治体の指定工事店しかできない**(水道法・下水道法)。宅内配管も原則同様。
   → ここは最初から外注前提で予算を組む。詳細は `04`。
3. **法規・制度は自治体と年度で変わる。**
   本ドキュメントは2025年4月の建築基準法・省エネ法改正を反映した一般論。
   **着工前に必ず、建設地の特定行政庁(市役所の建築指導課)と管轄消防署に事前相談すること。**
