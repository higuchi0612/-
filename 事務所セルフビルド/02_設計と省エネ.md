# 02. 設計と省エネ

「平屋・木造・100㎡以下」の枠内で、素人が破綻しない設計をするための指針。

---

## 1. 設計の進め方

1. **要件定義**: 何人が働くか、来客はあるか、駐車台数、将来の増員。
   - 目安: 事務スペースは1人あたり4〜6㎡ + 会議・水回り・倉庫。
   - 5〜8人の事務所なら 60〜85㎡(18〜26坪)で足りることが多い。
2. **ゾーニング**: 執務/会議/水回り(トイレ・給湯)/倉庫/玄関。水回りは1か所に固めると配管が短くなり、コストも施工難度も下がる。
3. **ラフプラン**: 方眼紙 or 無料CAD(「せっけい倶楽部」等)で平面図を描く。
4. **モジュールに乗せる**: 平面は**910mmグリッド(尺モジュール)**で描く。合板・石膏ボード・断熱材が全部このモジュール前提の寸法で売られており、加工が激減する。
5. **図面一式**: 配置図・平面図・立面図2面・矩計図(断面)・仕様書。プレカット業者に渡すと**伏図(構造の割付図)は業者側で描いてくれる**。

### 素人設計の鉄則

- **総2階ならぬ「総平屋の長方形」が最強。** 凹凸を作るほど、屋根の谷・外壁の入隅など雨漏りリスク箇所が増える。
- 屋根は**片流れ or 切妻**。寄棟・谷付きは避ける。
- スパン(梁の飛ばし距離)は**最大3,640mm程度**に抑えると一般流通材で組める。大空間が欲しければ柱を1本立てる勇気を持つ。
- 天井高は2,400mm前後。事務所の居室の天井高は**2,100mm以上**が法的下限。
- 採光・換気: 事務所は住宅ほど厳しくないが、居室には窓を確保(換気上有効な開口 or 24時間換気)。**シックハウス対策の24時間換気設備は事務所でも必須**。

## 2. 構造の基本(在来軸組・平屋)

「新3号」でも構造基準への**適合義務はある**。審査が省略されるだけで、守らなくていいわけではない。

| 項目 | 仕様の目安 |
|---|---|
| 基礎 | ベタ基礎(既知の領域。アンカーボルト・ホールダウン金物の位置は土台伏図と完全一致させる) |
| 土台・柱 | 105角(ヒノキ or 防腐防蟻処理材)。柱スパンは910〜1,820mm |
| 耐力壁 | 筋交い(45×90 たすき掛け)or **構造用合板9mm外張り**。素人には釘打ちだけで耐力が出る**合板耐力壁を推奨**(N50釘 @150mm、めり込ませない) |
| 壁量 | 2025年改正で必要壁量の基準が引き上げられた。**壁量計算は必ず行う**(無料の計算ソフト・プレカット業者のサービスあり)。平屋は元々余裕が出やすい |
| 金物 | 告示1460号どおりに柱頭柱脚金物を選定。プレカット業者に「N値計算と金物拾い」を依頼できる |
| 屋根 | 軽い屋根(ガルバ)にすると必要壁量が減り、全てが楽になる |

> 💡 **プレカット業者は「材料屋」ではなく「構造の相棒」。**
> 平面図・立面図を渡せば、伏図・壁量計算・N値計算・金物リストまでやってくれる(多くは加工費に込み)。
> 素人セルフビルドの構造品質は、実質ここで担保する。

## 3. 省エネ基準(2025年4月から全新築で適合義務)

- 事務所は「非住宅」。延べ300㎡未満の小規模なら、確認申請の中で簡素に扱われるが**適合義務はある**。
- 小規模非住宅は**モデル建物法**という簡易計算で適合を示すのが定番。無料のWebプログラム(国立研究開発法人 建築研究所の計算支援プログラム)で計算できる。
- 迷ったら「**仕様基準を上回る断熱をとりあえず入れる**」が正解:

| 部位 | 推奨仕様(6地域の目安) |
|---|---|
| 天井 | 高性能グラスウール16K 155mm以上 |
| 壁 | 高性能グラスウール16K 105mm(柱間充填) |
| 床 | 押出法ポリスチレンフォーム 65mm以上 |
| 窓 | **アルミ樹脂複合サッシ + Low-E複層ガラス**以上 |
| 換気 | 24時間換気(第3種でOK)+ 局所換気(トイレ・給湯室) |
| 照明 | 全てLED |
| 空調 | 壁掛けエアコン(能力計算は畳数表記でおおむね足りる) |

- 計算が不安なら、確認申請の代願と合わせて建築士に省エネ計算だけ外注する手もある(5〜15万円程度)。

---

## 4. 地盤調査と地盤改良

- 基礎工事の前に**SWS試験(スクリューウエイト貫入試験)**を必ず実施。5万円前後・半日。
- 結果が悪いと地盤改良(表層改良50〜100万、柱状改良100〜200万)が必要。**予算の最大の変動要因**なので、土地決定前に近隣の地盤情報(ジオダス等の無料DB)を見ておく。
- 改良工事は重機と品質保証の世界なので**外注一択**。

あとで決めると手戻りになるもの。図面確定前に全部決める。

- [ ] サッシの品番・寸法(→ まぐさ・窓台の位置が決まる)
- [ ] 玄関ドアの品番
- [ ] トイレ・給湯室の器具(→ 配管の立ち上げ位置が決まる)
- [ ] エアコンの位置(→ スリーブ・専用回路)
- [ ] 分電盤の位置と回路数(→ 電気屋との打合せに必須)
- [ ] 照明・コンセント・LAN・エアコンの位置を書いた**電気図**(コンセントは「思う数の1.5倍」が事務所の定石)
- [ ] 屋根材・外壁材の色番
- [ ] 24時間換気の給排気口の位置
