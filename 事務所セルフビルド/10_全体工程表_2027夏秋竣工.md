## 2. クリティカルパス

```
置場移設 → 地盤調査 → (改良要否) → 基礎
構造決定 → プレカット/鉄骨製作発注(納期1〜1.5か月) → 建て方
実施設計 → 確認申請(2〜4週) → 着工
```

この3本が同時に走る2026年9〜12月が勝負。**逆に、内装以降は自社ペースで調整可能**。

## 3. 遅延リスクと保険

| リスク | 影響 | 手当 |
|---|---|---|
| 置場移設先が決まらない | 全体スライド | 9月中に移設先を決める(仮置き含む) |
| 地盤改良が必要 | +2〜4週・最大200万 | 予備費で吸収。調査を10月までに終わらせ年内に改良完了 |
| 本業繁忙で自社班が抜ける | 内装期間が伸びる | 竣工目標に幅(夏〜秋)を持たせ済み。外装完了(2027-04)までは死守 |
| 確認申請の指摘 | +2〜3週 | 事前相談(建築指導課・消防)を申請前に済ませる |
| 200㎡超過 | 新2号化・審査やり直し | 実施設計で面積管理(194㎡+余裕6㎡)。増床要望はここで断る |
