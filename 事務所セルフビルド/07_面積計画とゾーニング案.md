# 07. 面積計画とゾーニング案

第1・2ラウンドの決定(平屋/役員個室なし/会議応接兼用/休憩室あり/予算2,000〜2,500万)に基づく計画案。
**実施設計(社内建築士)のたたき台**として使う。

---

## 1. 面積表(標準案: 延べ約137㎡ / 41.5坪)

| 室名 | 面積 | 内容 |
|---|---:|---|
| 風除室・玄関ホール | 8㎡ | 受付カウンター(事務席と対面)。来客はここで完結できる |
| 執務室 | 65㎡ | 固定9席(役員上座コーナー含む)+工務島8席+予備2席+複合機・収納 |
| 会議室(応接兼用) | 22㎡ | 12人会議(朝礼・安全会議・KY)+応接セット。玄関ホール直結で執務室を通さない |
| 休憩室 | 12㎡ | 給湯・ミニキッチン・冷蔵庫。昼食利用。勝手口(工場側)近く |
| トイレ | 12㎡ | 男子(大1・小1)+女子(2ブース)+手洗 |
| 書庫・倉庫 | 10㎡ | 工事書類・図面(建設業は書類保存義務が長い。可動棚推奨) |
| 廊下・設備 | 8㎡ | 分電盤・情報盤(LANハブ)・給湯器スペース |
| **合計** | **137㎡** | **41.5坪** |

- 外形の目安: **16.38m × 8.19m**(910モジュール 18×9マス=約134㎡)〜 奥行9.1mで約149㎡。実施設計で135〜150㎡に収める
- 200㎡以下の平屋 → 木造・鉄骨いずれでも「新3号建築物」で審査簡素
- 天井高2.5m推奨(事務所の法的下限2.1m。空調効率と開放感のバランス)

## 2. ゾーニング(概念図・向きは仮)

```
   既存工場・ヤード側                                前面道路側
 ┌────────────┬──────────┬────────────────────┬──────────────┐
 │ 休憩室 12   │ 書庫 10   │      執務室 65      │ 会議室(応接兼) │
 │ (給湯)      ├──────────┤  工務島8席│固定9席   │      22      │
 │ 勝手口 ─→  │ トイレ 12 │        (上座コーナー)├──────────────┤
 │            │ 男/女     │  受付カウンター ──→ │ 風除室+ホール 8│
 └────────────┴──────────┴────────────────────┴──────玄関────┘
```

**動線の設計意図**

- **来客**: 玄関 → ホール(受付) → 会議室。執務室に入れずに完結
- **工務(現場員)**: 工場側の勝手口 → 休憩室/書庫 → 執務室。泥・作業着動線を玄関と分離
- **事務**: 受付カウンター越しに来客一次対応。経理席は通路から画面が見えない向きに
- 水回り(トイレ・給湯)を1か所に集約 → 配管短縮・コスト減(`02`の原則)
- 🟥内での実際の向き(玄関を道路に向けるか駐車場に向けるか)は宿題の実寸確認後に決定

## 3. 予算配分の考え方(2,000〜2,500万円)

部屋数を絞った分、**予算は「性能と耐久」に振る**のがこの計画の方針。

| 優先度 | 投資先 | ねらい |
|---|---|---|
| ◎ | 断熱・サッシ(樹脂 or アルミ樹脂複合+Low-E複層、天井断熱厚め) | 光熱費と執務環境。省エネ適合も余裕でクリア |
| ◎ | **執務室のOAフロア(置敷き50mm)+Cat6A LAN** | 17席分の電源・LANを床下処理。レイアウト変更自由 |
| ○ | 空調のゾーン分け(執務2台+会議1台+休憩1台の壁掛け) | 会議室だけ・残業1人だけの運転ができる |
| ○ | 外壁・屋根の耐久グレード(ガルバ+高耐候シーリング) | メンテ周期を延ばす |
| △ | 太陽光(片流れ南向きなら好相性。既存工場で運用実績あり) | 自家消費型で電気代圧縮。第3ラウンドで判断 |
| 外構 | 駐車場土間・区画線・看板 | **舗装工事業の本業領域=ほぼ内製、外構費はほぼ材料費のみ** |

概算の目安(41.5坪・自社施工+専門外注):

| 費目グループ | 概算 |
|---|---:|
| 地盤調査・改良(未定・最大変動要因) | 5〜200万 |
| 基礎(自社・材料中心) | 90〜130万 |
| 構造体+建て方(木造 or 軽鉄 → `08`の相見積で確定) | 280〜450万 |
| 屋根・板金・樋 | 50〜90万 |
| サッシ・玄関・自動ドアなし想定 | 90〜150万 |
| 外壁・防水 | 90〜150万 |
| 電気(協力会社 or 社内資格者)+LAN・OAフロア | 120〜200万 |
| 給排水衛生・トイレ等器具 | 120〜200万 |
| 断熱・内装下地・仕上げ・建具 | 180〜280万 |
| 空調・換気 | 60〜120万 |
| 足場・仮設・申請・登記・保険 | 60〜100万 |
| 外構(内製・材料中心) | 40〜100万 |
| 予備費(10%) | 180〜220万 |
| **合計** | **約1,400〜2,400万** |

→ **予算2,000〜2,500万に対して、地盤改良が重くても収まるレンジ。** 相見積後に実行予算表(xlsx化推奨)に落とす。

## 4. 建築士に渡す設計与件メモ

- 用途: 事務所/平屋/延べ135〜150㎡/新3号を維持(200㎡以下)
- 構造: 木造在来(プレカット)と軽量鉄骨の比較中 → `08`の仕様で相見積、決定後に実施設計
- 省エネ: 2025年4月以降の適合義務対応(非住宅・モデル建物法)。仕様は上表の断熱方針
- シックハウス24時間換気(第3種)+局所換気
- 消防: (15)項事務所。消火器+規模により誘導灯 → 管轄消防署へ事前相談
- 敷地: 既存建物との同一敷地内新築。敷地全体で集団規定チェック(`00`の宿題完了後)
- 将来: 工務8名までの増員に席で対応(間仕切り変更なしで済むよう執務室は無柱が理想 → スパン計画に反映)
