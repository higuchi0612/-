## 2. 配置・ゾーニング(L字・向きは境界実測後に微調整)

```
                          道路(北)
        ┌───────────────┬────────────┐
        │  会議室 20     │ 風除室+ホール 8 │←玄関(北東角)
        ├───────────────┼────────────┤
  西    │                │            │   東:隣地駐車場
  自社  │   執務室 60(固定9席+島8席)    │   (境界50cm+
  ヤード │        上座コーナーは南側      │    離隔0.75〜1m)
        ├──────┬────────┬────────────┤
        │休憩10 │ トイレ12 │ 書庫8・廊下6 │
 ┌──────┴──────┴──┐─────┴────────────┘
 │                  │
 │    GYM 70        │   南: 隣家(離隔+窓配慮・騒音配慮)
 │  勾配天井3m超     │
 │  (片流れの高い側)  │←ヤードから直接入れる土間口
 └──────────────────┘
```

**設計意図**

- 来客動線: 玄関→ホール(受付)→会議室。執務室に入れず完結
- 工務・GYM動線: 西のヤード側から直接出入り(泥・トレ動線を玄関と分離)
- 水回り(トイレ・給湯)をL字の交点に集約 → 配管最短
- GYM翼は南西配置 → ラック落下音・バッグ打撃音が道路/隣地駐車場から最も遠い。ただし南隣家への騒音配慮(開口を絞る・防音断熱)は実施設計で
- 屋根: 各翼とも単純な片流れとし、**谷を作らない段違い納まり**で接続(雨仕舞い最優先の原則)
- 執務室9.1×7.28mは無柱(スパン計画条件 → `08`の見積条件と同じ)

## 4. 建築士に渡す設計与件メモ

- 用途: 事務所(+福利厚生GYM)/平屋/L字 合計194㎡目標・**200㎡以下厳守(新3号維持)**
- 構造: 木造在来 vs 軽量鉄骨比較中(`08`)。執務室9.1×7.28m無柱、GYMは勾配天井3m超
- GYM床: 土間コン(事務所FLと段差なし・ゴムマット厚さ分下げる)。ラック・スミスのアンカー固定前提
- サンドバッグ自立フレーム(動荷重各150kg級×2)の設置位置を土間配筋に反映
- 省エネ: 2025年4月以降の適合義務(非住宅・モデル建物法)。断熱は`02`仕様以上
- 24時間換気+GYM強制換気増強。消防((15)項)は管轄消防署へ事前相談
- 東境界(隣地駐車場): 離隔0.75〜1m・目隠し窓。南隣家: 離隔・騒音・日影配慮
- 将来: 工務8名増員対応(執務室レイアウト変更のみで可)
